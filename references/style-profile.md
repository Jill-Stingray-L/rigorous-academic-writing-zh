# 作者风格校准

仅在用户提供自己认可的既有文本并要求保持个人或团队风格时使用。Style Profile 是软约束，只在多种写法都准确、合规且等义时帮助选择，不是合格学术中文的必要条件。

## 一、样本与置信度

优先使用与目标文稿学科、文种和完成阶段相近的 2—5 篇定稿文本。模板语言、多人混写段落、原始草稿和当前待改文本降权。样本不足时只记录稳定可见特征，不推断作者偏好。

## 二、提取边界

只提取形式特征：

- 句段长度与信息密度的常见组合；
- 段首进入、段落推进和常用句法；
- 转折、因果、比较和限定方式；
- 引用嵌入、术语重复、缩写和中英文处理；
- 人称与标点偏好。

不提取或复制样本中的原句、事实、数据、案例、独有论证、引文和错误。风格学习不构成内容复用授权。

## 三、工作底稿

```json
{
  "sample_scope": "样本文种、学科和定稿状态",
  "confidence": "high | medium | low",
  "sentence_and_paragraph_rhythm": "稳定的句段组合与信息推进",
  "syntax_preferences": ["稳定出现的句法倾向"],
  "citation_integration": "引用如何嵌入命题",
  "hedging_and_transitions": "限定、转折、因果和比较习惯",
  "terminology": "术语、缩写和中英文处理",
  "person_and_punctuation": "人称及标点倾向",
  "avoid_in_target": ["与目标规范冲突或只在个别样本出现的形式"]
}
```

统计量只描述样本并触发复核，沿用 `SKILL.md` 的诊断—生成防火墙：不生成作者指纹、风格匹配分或目标区间，不通过随机拆句、补写、稀有词替换或功能词重配来拟合分布。

## 四、适用与回归

遵循 `事实与证据 > 学科规范 > 期刊或学校规范 > 文稿类型规范 > Style Profile`。校准后检查是否复制内容、改变数字引用术语或限定、把偶然特征写成偏好，或为接近统计分布生成无信息句子。第二轮没有新的具体问题时保持文本稳定。
