# 作者风格校准

本参考仅在用户提供自己认可的既有文本并要求保持个人或团队风格时使用。Style Profile 是软约束，不是合格学术中文的必要条件。

## 一、样本选择

优先使用与目标文稿学科、文种和完成阶段相近的 2—5 篇已定稿文本。把模板语言、多人混写段落、原始草稿和当前待改文本标记为低权重样本。样本不足时只记录能够稳定观察到的特征，不推断作者偏好。

## 二、只提取形式特征

可提取：

- 句长分布和长短句搭配；
- 段落长度与信息密度；
- 常用句法和段首进入方式；
- 转折、因果、比较和限定的表达方式；
- 审慎限定的使用习惯；
- 引用嵌入方式；
- 第一或第三人称偏好；
- 术语重复与缩写习惯；
- 括号、冒号、分号等标点习惯。

不提取或复制样本中的原句、事实、数据、案例、独有论证、引文和错误。风格学习不构成内容复用授权。

## 三、推荐结构

```json
{
  "sample_scope": "样本文种、学科和定稿状态",
  "confidence": "high | medium | low",
  "sentence_rhythm": "句长分布与常见组合",
  "paragraph_rhythm": "段落推进和信息密度",
  "syntax_preferences": ["稳定出现的句法倾向"],
  "citation_integration": "引用如何嵌入命题",
  "hedging": "限定和审慎措辞习惯",
  "transitions": "转折、因果和比较习惯",
  "terminology": "术语重复、缩写和中英文处理",
  "person_and_punctuation": "人称及标点倾向",
  "avoid_in_target": ["与目标规范冲突或只在个别样本出现的形式"]
}
```

统计量描述样本，不成为硬阈值。句长或段长与样本不同只能触发复核，不能通过随机拆分或补写句子来拟合分布。

## 四、适用优先级

应用 Style Profile 时遵循：

`事实与证据 > 学科规范 > 期刊或学校规范 > 文稿类型规范 > Style Profile`

个人习惯与术语标准、引用范围、证据强度或用户要求冲突时，采用前者中的正式约束。Style Profile 只在多种写法都准确且合规时帮助选择。

## 五、回归检查

风格校准完成后核对：

- 是否复制了样本中的内容而非形式；
- 是否改变数字、引用、术语或限定；
- 是否为了接近统计分布而产生无信息句子；
- 是否把低频偶然特征误写成作者习惯；
- 文稿第二次校准是否基本稳定。
