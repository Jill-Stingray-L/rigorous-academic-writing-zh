# 中文论文与报告的表达模式

本参考用于内容稳定后的终校。所有模式都是语境复核线索：词语、句式、标点、句长或段落形态只有造成事实不清、逻辑不明、证据越界、指代困难、机械重复或不符合目标学术语体时才修改。

三项并列、问句、比喻、被动表达、名词化、长句、短句、分号、显式连接词以及某种句段分布都不是独立错误。表达审校不得越过 [研究严谨性与证据](rigor-and-evidence.md) 已确认的主张边界，也不得破坏 [文档建模与审计流程](document-model-and-audit.md) 记录的信息锚点和句子功能。

## 一、直接进入与信息增量

必要背景明确后，段落从研究对象、材料、问题、判断或结果进入。遇到“随着……不断发展”“在当今……背景下”“众所周知”“在深入讨论之前”“值得注意的是”等起笔，检查它是否提供不可缺少的时间、政策、范围、研究动机或歧义说明；没有增量时删除，有功能时具体化。

段末落在本段得到的结果、解释边界或下一步输入上。“由此可见”“综上所述”“这表明”“具有重要意义”等引导语只有在其后提高分析层级或给出新判断时才保留；同义复述应合并。

## 二、具体动作与准确命名

“构建机制、形成体系、实现赋能、提供支撑、推动落地、发挥作用”等抽象组合如果隐藏研究动作，应恢复执行者、材料、操作和可核验结果。成果名称的完整性与层级按通用证据规则审计，语言终校只负责让名称和实际内容一致，不用更宏大的词替换具体成果。

没有正式定义的项目化组合词应改为通行术语，或在首次承担分析功能前给出足够定义。术语重复有助于追踪，不以近义词轮换同一对象来制造变化。

## 三、指代与中英文处理

“该资料、上述对象、相关内容、这一结果、部分系统、其”等指代必须有唯一先行词。先行词较远或可能指向多个对象时直接恢复名称。

同一外文术语采用一个确认的中文名称和缩写。首次出现按目标规范给出中英文或缩写，后文不反复双写；不同译名只有在比较学术传统或概念边界时并列。

## 四、翻译腔与句法层级

检查过长前置定语、主谓距离过远和多层“对……的……的……进行……”。中文通常先明确对象和动作，再补充条件；拆句时保留原有限定关系。

“对于 X 来说”“就 X 而言”“在 X 方面”只在切换比较维度、限定范围或消除歧义时保留。X 能直接充当主语或对象且话题壳无功能时，直接进入判断。

连续“的”链应区分分类、所属和动作关系，可通过恢复动词、使用“其中”或“由……构成”、拆分定义与限定来处理；不按字数机械删词。“其”只在指向唯一且能缩短句子时使用，相邻句反复出现时恢复明确主语。

名词化只有在隐藏执行者、动作、对象或使修饰层级难以解析时才改写；结构清楚且符合学术语体时保留。

## 五、句法、节奏与衔接

一个句子应有可识别的主要判断和必要限定。长句本身不是错误；背景、方法、结果和意义被逗号或分号串联并导致判断层级难以理解时，才按语义边界拆分。

句长变化来自真实的条件、比较、机制、结果和限定关系。统计发现句段均一时，继续检查句法骨架、段落功能和信息推进是否同时同构；没有结构问题则不为制造波动而拆句、补写空句或替换稀有词。

连接词必须标记真实关系：“同时”表示并行，“因此”表示推论，“其中”引出集合成员，“相比之下”需要明确比较对象。重复连接词只是复核入口；应修复实际的机械列举或关系缺失，而不是轮换同义词。

并列数量服从真实分类和权重。确有三个对象时保留，不因“三项式”外观随意增删；不同权重的内容不强写成对称排比。

## 六、归因、澄清与评价语气

“研究表明、专家认为、业内普遍认为、相关资料显示”应紧邻可核验来源。来源只与主题相关而不支持相邻命题时，调整命题或来源。

“这并不意味着……”“不能理解为……”“需要说明的是……”应有真实前置对象，如合理歧义、实际争议、研究设计边界或结果解释限制；找不到前置对象时删除自设问题。

“至关重要、深刻揭示、显著赋能、开创性、全方位、奠定坚实基础、前景广阔”等评价需要具体比较、机制或结果支持。缺少支持时改为可观察事实。强结论词的证据要求由通用证据规则决定，不能只靠降调词替换掩盖证据缺口。

## 七、正文状态与协作痕迹

正式正文清除聊天话语、修改提示、待办、内部尝试、被排除方案和制作说明；它们只有本身构成方法或论证时才保留。出版规范要求的图注、表注、脚注、数据可用性声明和来源项按目标格式保留。

正向定义优先：研究正文优先说明对象是什么、适用什么条件、采用什么规则和形成什么结果。连续通过“不是什么、不能怎样、不属于什么”界定对象时，检查这些排除是否具有独立论证价值；没有真实概念混淆或前置争议时，直接陈述对象、模型不变量、证据条件或目标状态。

否定内容可能是科研严谨性所必需的；审校对象是无必要的反向定义、连续否定堆积和规范说明书式语气，不是所有否定句。真实排除标准、限制条件、阴性结果、未验证状态、因果与分类边界、结构适用与运行验证边界以及风险提示必须保留。处置分为三类：必要边界保持原意；边界必要但句法绕行时，用正向证据条件或规则重述；只有否定在回应不存在的问题或排除无关对象时才删除或重写。

脚本命中按 `形式候选 → 真实前置对象检查 → 证据边界判断 → 最小修改` 处理，不据否定词数量自动改写。

## 八、终校步骤

1. 标记数字、公式、引文、术语、标签和限定条件，确认改写前后等义。
2. 为每段写出中心任务；无法概括时先修复论证，不直接做表面润色。
3. 检查段首、段末和相邻段之间是否有信息推进。
4. 检查指代、术语稳定、中英文处理和首次使用后的名称一致性。
5. 检查翻译腔、抽象动作、归因、澄清、正向定义、必要否定边界、评价语气和重复衔接。
6. 清除协作残留和异常格式。
7. 第二轮只处理新发现的具体问题；没有问题时保持原文。
